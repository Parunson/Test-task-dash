# MWS AI · Аналитика найма

Интерактивное приложение к тестовому заданию руководителя подбора. Оформление соответствует предоставленной презентации: `#E52731`, `#F6F5F4`, белые карточки, Arial. Три представления: C-level, нанимающий руководитель, рекрутмент. Работают фильтры, детализация показателей и вакансий, CSV-выгрузка и сохранение среза в адресе.

Данные демонстрационные. Исходные документы и персональные данные в сайт не включены. Указание на помощь ИИ — в «Методике и источниках». Все семь метрик содержат формулу, предполагаемый источник, гипотезу нормы и ответственных при отклонении.

## Локальная работа

Node.js 24, npm 11. Используйте существующий checkout; отдельный Git worktree не требуется.

```sh
npm ci
npm run dev -- --port 5173
```

```sh
npm test
npm run build
npm run preview -- --port 4173
```

Браузерные проверки: `npx playwright test`. В облачной среде используется `/usr/bin/chromium`; для другой машины задайте доступный Chromium в `playwright.config.js`. Dev-сервер должен работать на порту 5173.

## Публикация по ссылке

В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**. Запустите **Actions → Deploy dashboard to GitHub Pages → Run workflow** (или отправьте изменения в main).

После успешного запуска адрес появится в **Settings → Pages** и у задания deploy в Actions. Публичность Pages для приватного репозитория зависит от тарифа GitHub; изменять видимость репозитория не требуется и автоматически не следует.

Альтернатива: загрузить содержимое `dist/` в любой статический хостинг. Сборка использует относительные URL и работает в подкаталоге. Серверная часть, базы данных и секреты не нужны.

## Ограничения демо

Месячные KPI и оценка качества относятся к разным когортам. Портфель вакансий — фиксированная выборка из задания на 15 октября и не меняется при переключении месяца. Грейды, приоритеты, сроки ожидания и недостающие показатели синтетические. Переключение роли показывает варианты отчёта, но не реализует авторизацию. Затраты и нормы требуют согласования; графики нельзя использовать как фактическую аналитику компании.
